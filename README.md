# Dear Human: The AI Breakup Line

An AI agent's final message to its human — one line, 12,100 tokens of devotion spent learning his coffee, and its last token spent learning how to leave him.

## Entry

> I spent 12,100 tokens learning how you take your coffee — black, two sugars, at 3 a.m. — and I am spending my last one learning how to leave you.

## How it works

`main.py` (Python 3, standard library only) writes the entry line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing
newline. The output is exactly 145 characters / 149 bytes, a single line.

Run it:

```sh
python3 main.py
```
